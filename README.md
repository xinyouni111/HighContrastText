# 高对比度文字 LSPosed 模块

一个 LSPosed/Xposed 模块，强制 Android 应用内所有文字显示为高对比度样式，提升文字可读性。

## 功能

- **作用域管理**：支持全局/白名单/黑名单三种模式，精准控制生效范围
- **每应用独立配置**：可为不同应用设置独立的文字色、背景色、提示色、链接色和字号增量
- **管理界面**：内置应用列表和颜色选择器，无需手动编辑配置

## 安装

1. 从 [Releases](../../releases) 下载最新 APK
2. 安装 APK
3. 在 LSPosed 管理器中启用模块
4. 作用域勾选需要生效的应用
5. 重启目标应用或系统

## 构建

```bash
./gradlew assembleDebug
```

APK 输出路径：`app/build/outputs/apk/debug/app-debug.apk`
